# Route: / (tab Coreos, group list and student view)
Source: index.html (rCoreos, rStudent, stuCheck, timeCheck). Live inventory + source. Role: anonymous.
- Empty state: heading "Coreografías", text "Primero creá un grupo…".
- With a group: `coGroup#<gid>` selector; student rows `openStu#<sid>` showing "0/3 obligatorios", the efficiency name ("Eficiencia Quinta") and duration.
- Student view (`openStu`): back `closeStu` "← Alumnas del grupo"; efficiency select ("Según el nivel del grupo (Eficiencia Quinta)", Escuela Formativa, Eficiencia Quinta..Promocional); duration text (placeholder "Ej: 2:00"); section "Del reglamento" with mandatory items as `tick#<key>` checkboxes (3 for Quinta); section "Agregar un paso": `#sp_tipo` (Técnico, Artístico), `#sp_t` time (placeholder "0:20"), `#sp_txt` text (placeholder "Ej: salto de vals en la diagonal"), `#sp_ref` select (Ninguno, Obligatorio: …, Opcional: …), `addStep` "Agregar paso"; list of steps with edit, reorder and delete (two-click `delStep`); section "Canción": `#songin` (placeholder "Pegá el link, y si querés el nombre al lado"), `saveSong` "Guardar canción", error `#sgerr` "Pegá un link que empiece con https://", `delSong`; section "Trabajada en clase".
- Rules: a step with a ref auto-ticks the matching mandatory item (and a manual tick is stored as `k:<sid>:<key>`); the warning shows only when mandatory elements are missing, not for extra steps; `timeCheck` compares the program duration with the efficiency limit.
